# 기말 벼락치기 장표

시기해부학, 안경조제가공이론, 기하물리광학, 굴절검사·안경광학, 조제실습·콘택트렌즈 기말용 프린트 PDF를 바탕으로 만든 정적 장표형 학습 사이트입니다.

- 원본 PDF 전체 파일과 개인정보는 포함하지 않았습니다. 추가 과목은 학습에 필요한 핵심 그림만 웹용 이미지로 축소했습니다.
- 시기해부학 65개, 안경조제가공이론 79개, 기하물리광학 110개 문항과 김미진·류동규 추가 프린트 핵심 문항을 장표로 재구성했습니다.
- 각 문항마다 쉬운 개념 설명, 암기법, 출제 포인트를 넣었습니다.
- 과목 메뉴에서 시기해부학, 안경조제가공이론, 기하물리광학, 굴절검사·안경광학, 조제실습·콘택트렌즈를 각각 따로 볼 수 있습니다.
- 이미지가 중요한 추가 과목은 PDF 핵심 그림을 웹용 이미지로 넣고, 그림에서 봐야 할 포인트를 같이 정리했습니다.
- 브라우저에서 `site/index.html`을 열거나 정적 서버로 `site/`를 배포하면 됩니다.

## 로컬 실행

```powershell
python -m http.server 5173 -d site
```

## Cloudflare Pages

```powershell
npx wrangler pages deploy site --project-name jeongeun-final-cram
```
